
<h1 align="center">SmeltingOreCompat</h1>

<p align="center">A lightweight QOL mod that makes processing ores faster in tech modpacks.</p>

<p align="center"><b>Minecraft 1.21.1 · NeoForge 21.1.x · MIT License</b></p>

# **✨ Features**

- 🔥 **Campfire smelting** – cook ores, raw materials, dusts, clumps and more straight into ingots
- 🧱 **Raw block smelting** – turn raw ore blocks into full storage blocks (1:1, 9 ingots worth)
- 🛡️ **Safe loading** – recipes only load if the target mod is installed, so no errors

# **⏱️ Smelting Speed**

| Recipe | Campfire | Furnace | Blast Furnace |
|---|---|---|---|
| Ores, dusts, clumps → ingots | 10 ticks (0.1 XP) | – | – |
| Raw blocks → storage blocks | 100 ticks (0.9 XP) | 50 ticks (10 XP) | 50 ticks (10 XP) |

# **🔧 Supported Mods**

| Mod | What it covers |
|---|---|
| FTB Materials | shard, dust, dirty dust, raw ore, raw block |
| Create | crushed raw ore, dust |
| Mekanism | raw ore, dust, dirty dust, clump |
| Oritech | raw ore, raw ore block |
| All The Ores | dust, raw ore, raw ore block |
| Deeper and Darker | ore blocks (e.g. Gloomslate ores) |

# **📦 Installation**

1. Install NeoForge for Minecraft 1.21.1
2. Download the `.jar` from the **Releases** page
3. Put it in your `mods` folder
4. Launch the game and enjoy
